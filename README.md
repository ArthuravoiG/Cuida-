Aplicativo feito para auxiliar idosos a controlar os horários dos remédios feito em Dart.

# Cuida+

Aplicativo desenvolvido em Flutter/Dart 
## Tecnologias
- Flutter
- Dart

## Como executar
1. Instale o Flutter (https://docs.flutter.dev/get-started/install)
2. Clone o repositório: `git clone https://github.com/ArthuravoiG/ProjetoCuidaMais.git`
3. Execute: `flutter pub get` e depois `flutter run`
